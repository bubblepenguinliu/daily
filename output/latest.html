llm-echo 0.5

Simon Willison 更新调试插件 llm-echo，模拟 token 用量计入工具调用与推理 token。

17 段· 9 条批注

2026 年 10 月 18 日

我正在准备一个新的 LLM 版本发布，测试 PR 时让我重新审视了 llm-echo 这个调试插件。这个插件提供了一个完全不涉及 LLM 的“模型”——它只是把喂给它的 prompt 原样重复回来。新版本现在会更新模拟的 token 用量计数，把 tool calls、system prompts 和 reasoning tokens 都纳入计算。

背景llm 是 Simon Willison 开发的命令行工具，通过插件机制接入各家模型；llm-echo 属于“假模型”插件，用于在不调用 API、不花钱的情况下测试上层逻辑。
实操用 `llm plugins` 可列出已安装插件，`llm -m echo --help` 查看该假模型支持的选项；调试自己的 llm 插件时，把 echo 当 mock 后端最省事。
延伸同类“无 LLM 假模型”在测试生态里很常见，如 OpenAI 兼容的 mock server、vLLM 的 dummy 模型；核心思路都是把 token 计数与网络调用解耦。

示例用法：

uvx --with llm-echo llm -m echo 'hi there' -o thinking 1 --usage

背景uvx 是 uv 提供的临时运行器，`--with` 会在隔离环境里额外装包再执行命令，等价于一次性 venv + pip install，不污染全局环境。
实操`-o thinking 1` 是模型选项（option），`--usage` 打印 token 统计；这两个参数组合正好验证新版本对 reasoning tokens 的模拟是否生效。

输出：

First I consider the prompt, then I decide what to say.

质疑这行是 echo 模型伪造的“思考内容”，并非真实推理；它只用于占位，别把它当成模型行为的证据。

"prompt": "hi there",

"system": "",

"attachments": [],

"stream": true,

"previous": [],

Token usage: 2 input, 24 output

数据输入 2 个 token 对应 “hi there” 两个词；输出 24 个 token 里包含那句伪造的 thinking 文本，说明 reasoning tokens 被计入了 output 侧。
延伸真实 API 中 reasoning tokens 通常单独计价或计入 output，各家口径不一（如 OpenAI 计入 output、Anthropic 单列），echo 的模拟只代表 llm 工具自身的记账约定。

18th October 2026

I'm working towards a new LLM release, and testing PRs caused me to revisit the llm-echo debug plugin. This plugin provides a "model" which doesn't involve an LLM at all - it just repeats back the prompts that have been fed to it. The new release now updates the simulated token usage counts to take tool calls, system prompts, and reasoning tokens into account.

Example usage:

uvx --with llm-echo llm -m echo 'hi there' -o thinking 1 --usage

Outputs:

First I consider the prompt, then I decide what to say.

"prompt": "hi there",

"system": "",

"attachments": [],

"stream": true,

"previous": []

Token usage: 2 input, 24 output
